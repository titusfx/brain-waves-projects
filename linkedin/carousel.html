Why nobody had this working · 2017 → 2025

Neither bug was the crypto.

1 · It picked the wrong key

emokit chooses its AES key with serial.startswith("UD2016") — a literal string test. My dongle is a 2018 unit, so it silently took the wrong key and printed confident garbage. No exception. No warning.

2 · It read the bytes backwards

Every 16-bit sample field was decoded big-endian. They are little-endian. Same offsets, opposite order — which is why the output still looked like a signal for eight years.

The offsets were right. The byte order was wrong. 8 / 11

Why you can believe it · two oracles

A wrong key never throws.

It produces beautiful, plausible, meaningless numbers. So nothing here is claimed without a check a wrong key cannot pass:

1

Byte 1 must collapse

Correct: 2 distinct values (0x10 / 0x20). Wrong: ~256.

2

Autocorrelation

Real EEG is band-limited and correlated in time. Noise is not.
